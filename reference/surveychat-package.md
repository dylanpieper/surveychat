# surveychat: Adaptive Surveys and Forms with LLM Validation for 'shiny'

Collect survey data in 'shiny' with a chat, a form, or both, and let the
user switch between them. One question spec drives both views. An LLM
validates each answer against a plain-language rule, extracts structured
data, and writes adaptive questions from earlier answers. Raw and
extracted answers are stored on any 'DBI' backend.
