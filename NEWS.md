# surveychat (development version)

* `run_example()` has a new `chat` argument. Use a string such as `"openai/gpt-4.1-mini"`, an ellmer chat, or the environment variable `SURVEYCHAT_CHAT` to run the example with any LLM. The example has no default model. A chat with missing credentials now stops in the console, before the app opens.
